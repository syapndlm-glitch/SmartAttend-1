Project Name: SmartAttend

Description:

SmartAttend is a real-time web-based attendance system designed to prevent proxy attendance in classrooms. It generates a 6-character security code and matching QR code that automatically rotates every 60 seconds. Students scan the QR code to check in, and their attendance instantly syncs to the teacher's live dashboard using Firebase Realtime Database.

Key Features:

Automated 60-second code & QR code rotation

Direct QR scan for instant student entry

Real-time Firebase data synchronization and live student counter

Roster reset button for new sessions

Tech Stack: HTML5, CSS3, JavaScript (ES6+), Firebase Realtime Database, QRCode.js
